# Listing Writer

Turn a product name and a few details (plus an optional photo) into a ready-to-paste Etsy or eBay listing: a title, a description and 13 search tags.

Built for the Hacktoberfest 2026 Open-Source AI Challenge (Week 2: Side Hustle).

## Built with

- **Gemma 3 (4B)**, Google's open-weight model
- **Ollama** to serve the model locally
- **Gradio** for the web interface

No paid API: every listing is generated by an open model running on your own hardware or a free Colab GPU.

## Run it in Google Colab (no install)

1. Open `listing_writer_colab.ipynb` in [Google Colab](https://colab.research.google.com).
2. Go to **Runtime > Change runtime type > T4 GPU** and save.
3. Run the three cells in order:
   - Cell 1 installs Ollama and the Python libraries.
   - Cell 2 starts Ollama and downloads Gemma.
   - Cell 3 starts the app.
4. Open the `gradio.live` link printed by Cell 3.

## Run it on your laptop

```bash
# 1. Install Ollama from https://ollama.com
ollama pull gemma3:4b
pip install "gradio<6" ollama
python listing_writer.py
```

Then open http://127.0.0.1:7860. Run locally, your product details and photos never leave your machine.

## Note

Small models can still make mistakes, such as calling an IPX5 product "waterproof". Always check a listing before publishing it.
